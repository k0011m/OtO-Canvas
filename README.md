- 再生・もう一度見る・作品棚の「みる」・MV保存の開始時に、現在の作品から主旋律と伴奏をWeb Workerで生成します。準備中は図形のアニメーションを表示し、「もどる」で中止できます。重複要求と中止後の再生を防ぎ、失敗・60秒のタイムアウト時は再試行できます。
- MVは事前に全フレームを生成せず、再生中に時刻に合わせて描画します。編集用BGM・図形の試聴・音階プログラムの試聴は従来どおり使えます。
- WAV保存は直前に再生準備した現在の作品の音を使います。未再生・編集後の場合は、先に再生するよう案内し、保存ボタンから新たに作曲しません。
- Workerもオフラインキャッシュの対象です。PWAの旧版が残っている場合は、おとな向け設定から更新してください。ネイティブストア版の作成・配信は今回の変更に含みません。

## 記念撮影

完成画面の体験アンケートは、撮影・編集へ戻る操作と同じカード型ボタンで表示します。

保護者がカメラを許可した場合、完成画面から撮影できます。「ピース！ とる」を押すと、映像の中央に3・2・1を1秒ずつ表示して撮影します。撮影前に内カメラ・外カメラを切り替えられます。内カメラは鏡像、外カメラは通常向きでプレビュー・JPEGを作ります。切り替え時には前のカメラを停止します。写真は送信されず、保存は利用者の操作で行います。

### 変更履歴：2026-10-13

- `CelebrationCamera.tsx`・`global.css`：映像中央の3秒カウントダウン、カメラ切替、終了時の撮影予約取消を追加。
- `cameraSettings.ts`：`openCamera(facing)`を追加。既存の`openFrontCamera()`は保護者の許可確認用として維持。
- 外カメラがない端末や対応しないブラウザでは案内を表示し、内カメラへ戻せます。カウント中は二重撮影と切替を無効にし、閉じる操作は可能です。
