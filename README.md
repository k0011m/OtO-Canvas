# OtO-Canvas

## バージョン 0.2.0 / 再生時の作曲

- Home画面の右下に`ver 0.2.0`を表示します。表示元は`package.json`の`version`です。今後のリリース時は`package.json`と`package-lock.json`を同じバージョンに更新してビルドします。ブラウザ・インストール済みPWAで、実際に読み込んだ版を確認できます。
- 編集・自動保存・作品ファイルの入出力・コピーでは、`createDraftProject()`が図形や設定だけを保存し、`events`は空配列にします。既存の作品ファイルも読み込み可能です。
- 再生・もう一度見る・作品棚の「みる」・MV保存の開始時に、現在の作品から主旋律と伴奏をWeb Workerで生成します。準備中は図形のアニメーションを表示し、「もどる」で中止できます。重複要求と中止後の再生を防ぎ、失敗・60秒のタイムアウト時は再試行できます。
- MVは事前に全フレームを生成せず、再生中に時刻に合わせて描画します。編集用BGM・図形の試聴・音階プログラムの試聴は従来どおり使えます。
- WAV保存は直前に再生準備した現在の作品の音を使います。未再生・編集後の場合は、先に再生するよう案内し、保存ボタンから新たに作曲しません。
- Workerもオフラインキャッシュの対象です。PWAの旧版が残っている場合は、おとな向け設定から更新してください。ネイティブストア版の作成・配信は今回の変更に含みません。

- `src/app/App.tsx`：編集時の作曲メモ化を廃止し、明示的な再生要求で生成。準備画面・中止・失敗案内・Homeのバージョンを追加。
- `src/music/arranger.ts`：保存専用の`createDraftProject()`と`generateEvents`オプションを追加。既存の`createProject()`の既定動作は互換性のため維持。

- `src/styles/global.css`・`package.json`・`package-lock.json`：準備演出、バージョン表示、0.2.0への更新。
- `tests/deferredComposition.test.ts`・`e2e/deferred-composition.spec.ts`：保存時に作曲しないこと、再生時の生成、中止・再試行を検証。既存の音階・撮影・オフラインテストを新しい再生タイミングに対応。

3〜8歳のお子さまが、音楽と動画づくりを楽しめる創作サービスです。
図形を置いたり絵を描いたりすると、自分だけの30秒の作品になります。
図形の色・大きさ・配置を変えて、好きな見た目をつくれます。
声やおもちゃの音、楽器の音、電子音から好きな音の世界を選べます。
15種類の動きを組み合わせて、図形を踊らせられます。
6〜8歳向けには、ドレミと音を鳴らす順番を決める遊びもあります。
再生中に図形をタップすると、音を加えて演奏に参加できます。
作品を保存して遊び直したり、動画として書き出したりできます。
保護者がお子さまに合わせて使える機能を選び、一緒に楽しめます。

## 記念撮影

保護者がカメラを許可した場合、完成画面から撮影できます。「ピース！ とる」を押すと、映像の中央に3・2・1を1秒ずつ表示して撮影します。撮影前に内カメラ・外カメラを切り替えられます。内カメラは鏡像、外カメラは通常向きでプレビュー・JPEGを作ります。切り替え時には前のカメラを停止します。写真は送信されず、保存は利用者の操作で行います。

### 変更履歴：2026-10-13

- `CelebrationCamera.tsx`・`global.css`：映像中央の3秒カウントダウン、カメラ切替、終了時の撮影予約取消を追加。
- `cameraSettings.ts`：`openCamera(facing)`を追加。既存の`openFrontCamera()`は保護者の許可確認用として維持。
- 外カメラがない端末や対応しないブラウザでは案内を表示し、内カメラへ戻せます。カウント中は二重撮影と切替を無効にし、閉じる操作は可能です。
